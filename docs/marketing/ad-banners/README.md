# Ad banner kit

Ready-to-upload creatives for paid promotion of SaloAleh. Five concepts × eight
formats × two locales, generated from source so a copy change is a one-line edit
and a re-run — not a redraw.

Generated by [`scripts/marketing/build-ad-banners.js`](../../../scripts/marketing/build-ad-banners.js);
design lives in [`banner-design.js`](../../../scripts/marketing/banner-design.js).
**Do not hand-edit the images** — they are overwritten on every build.

```bash
node scripts/marketing/build-ad-banners.js --locale=ar,en
```

Needs only Node ≥ 22 and a Chromium binary (auto-detected; override with
`CHROME_PATH`). Fonts and the app icon are inlined from the repo, so there is no
network dependency and the output is byte-stable across machines.

## The five concepts

Each leads on a different hook — run them against each other and keep what converts.

| # | Concept | Hook | Palette |
|---|---------|------|---------|
| `01-compete` | Global leaderboard | "Send salawat and compete with the world" — the top-3 board | Ink + gold |
| `02-friday` | Friday ×2 | Double points on the best day of the week | Emerald + gold |
| `03-streak` | Seven-day streak | Seven days in a row earns a badge | Ember |
| `04-community` | One ummah | Countries apart, united in salawat | Ink + gold |
| `05-onetap` | One tap | The lowest-friction pitch: free, no sign-up | Near-black + gold |

Every claim in the copy maps to a shipped feature — the weekly round and live
leaderboard, the `mohamed_lovers_friday_bonus_label` ×2 multiplier, the 7-day
`ROUND_STREAK_TARGET` badge, and identity without accounts. **No creative states
a user count, country count or total-salawat figure**: those move week to week
and would date the asset (and invite a "misleading claim" review). If you add a
numeric claim later, re-verify it against `stats.json` first.

## Formats

| File | Size | Where it goes |
|------|------|---------------|
| `feed-1200x628` | 1200×628 | Meta / Google Display landscape feed |
| `square-1080x1080` | 1080×1080 | Meta & Instagram feed |
| `story-1080x1920` | 1080×1920 | Stories / Reels |
| `mrec-300x250` | 300×250 | AdMob & GDN medium rectangle — the workhorse |
| `lrec-336x280` | 336×280 | GDN large rectangle |
| `leaderboard-728x90` | 728×90 | GDN desktop leaderboard |
| `mobile-320x100` | 320×100 | AdMob large mobile banner |
| `sky-160x600` | 160×600 | GDN wide skyscraper |

Layout is per aspect-ratio family, not per size: a wide feed unit, a square, a
portrait story, a box, a strip, a mobile bar and a tall rail. 336×280 is the
300×250 layout rendered at 1.12× so the two stay identical in proportion.

## Files

```
docs/marketing/ad-banners/{ar,en}/{concept}/{format}.{png,jpg}
manifest.json      # every file with its exact byte size
```

- **PNG** for the five display-network sizes — they must stay under Google's
  150 KB per-image ceiling, and all of them land under 75 KB. The build prints a
  warning if one ever crosses it.
- **JPG** (quality 88) for the three large social sizes, which is what Meta and
  Instagram want. No lossless twin is committed: at ~600 KB each they would add
  around 18 MB for files nobody uploads, and the generator reproduces them
  exactly on demand — flip the format's `jpg` flag to get PNG instead.

## Before you upload

- **Arabic is the primary set.** The English set exists for non-Arabic targeting;
  don't run it at Arabic-speaking audiences.
- **Story safe zones**: `story-1080x1920` keeps all copy inside the middle ~70%,
  clear of the Instagram profile row and the swipe-up bar.
- **Meta text-in-image**: the hard 20% rule is gone, but heavy text still
  suppresses delivery. The feed and square units are deliberately light on copy;
  don't add more in the ad-platform overlay.
- **Landing page**: point every creative at
  `https://play.google.com/store/apps/details?id=tools.mo3ta.salo`.

## Changing something

| You want to | Edit |
|-------------|------|
| Reword a concept | Its `ar`/`en` block in `CONCEPTS` (`banner-design.js`) |
| Add a sixth concept | Append to `CONCEPTS` + add its art function to `ART` |
| Add an ad size | Append to `FORMATS`; reuse a `family`, or add one to `LAYOUTS` + `FAMILY_CSS` |
| Recolour | `THEMES` — palette is taken from `landing.html` |

`short` is the one-line version used on the formats with no room for a
headline/sub pair (box, strip, mobile, skyscraper). Keep it genuinely short or
it will ellipsize in the 728×90 strip.

Preview a single creative fast:

```bash
node scripts/marketing/build-ad-banners.js --only=02-friday --format=feed-1200x628
```
